# Парсер Wildberries

Собирает данные о товарах с Wildberries: название, артикул, цену, ссылку.

## Как работает
- Открывает главную страницу Wildberries через Selenium.
- Скроллит страницу, чтобы подгрузились карточки товаров.
- Извлекает данные через XPath.
- Сохраняет результат в CSV-файл.

## Технологии
Python, Selenium, Pandas, XPath

## Как запустить
1. Установить зависимости: `pip install selenium pandas`
2. Запустить скрипт: `python parser.py`
3. Результат появится в файле `wildberries_products.csv`
